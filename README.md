# EddyFlow

Code accompanying the **EddyFlow** paper: downscaling coarse ERA5 atmospheric
reanalysis (0.25°) to fine-resolution sea surface temperature (SST) matching
MUR satellite data (0.01° / ~1 km). The primary training domain is the Gulf
of St. Lawrence (GSL); Bay of Fundy, Labrador Sea, and Gulf of Mexico are
used for out-of-domain evaluation.

This repository contains **only the code** needed to reproduce the data
pipeline, training, and evaluation described in the paper. It does not
include pretrained model weights, raw/processed datasets, or any figures —
these are regenerated by running the pipeline below.

## Repository layout

```
src/
  config.py                 # Hyperparameters + paths
  model.py                  # Encoder/decoder/diffusion model classes (stages 1-5, V2)
  dataset.py                # Dataset + dataloader construction
  train.py, trainv2.py      # Phase-1 training entry points
  finetune_diffusion.py, finetune_diffusion_v2.py,
  finetune_fewshot.py, finetune_sweep_v2.py   # Phase-2 diffusion fine-tuning
  evaluate.py, evaluate_v2.py, eval_bof.py, eval_gom.py  # Evaluation
  plot_sweep.py             # Sweep result plotting

scripts/
  download_domains.py, download_era5.py, download_mur.py,
  download_glorys.py, download_gebco.py   # Data acquisition
  preprocess.py, preprocess_gebco.py      # Build zarr/npy training tensors
  compute_stats.py                        # Normalisation statistics
  data_analysis.py                        # Per-domain bias/RMSE analysis
  compile_ablation.py, compile_gom_results.py,
  make_paper_figures.py, make_qualitative_figure.py,
  make_fewshot_figures.py, make_sst_animation.py,
  explore_bar_charts.py, explore_qualitative.py   # Result/figure generation
  eval_era5_sst_baseline.py, eval_wenhai_corrected.py, wenhai_eval.py,
  prepare_wenhai.py         # Baseline comparisons
  sweep/                    # SLURM hyperparameter sweep infrastructure

*.sh   # SLURM job scripts (data download, training, fine-tuning, evaluation)
```

## Requirements

- Python 3.10+ (3.11 recommended for the data-processing scripts, which use
  `proj`/`geos`/`gdal`/`netcdf`)
- PyTorch with CUDA support
- `xarray`, `zarr`, `numpy`, `scipy`, `cartopy`, `netCDF4`

Install dependencies for your environment, e.g.:

```bash
pip install torch xarray zarr numpy scipy cartopy netCDF4 pyproj
```

Cartopy/PROJ can require system-level GEOS/PROJ/GDAL libraries; on an
HPC/module-based system load these before installing, e.g.:

```bash
module load python/3.11 proj geos gdal netcdf hdf5
```

## Reproducing the pipeline

### 1. Download raw data

```bash
python scripts/download_domains.py --domain gsl   # ERA5 + MUR for the training domain
python scripts/download_era5.py ...
python scripts/download_mur.py ...
python scripts/download_glorys.py ...
python scripts/download_gebco.py ...
```

See each script's `--help` for domain/date-range arguments. `data.sh`,
`data2.sh`, `data3.sh`, and `data_gom.sh` show example SLURM submissions for
different domains.

### 2. Preprocess into training tensors

```bash
python scripts/preprocess.py --domain gsl
python scripts/preprocess_gebco.py
python scripts/compute_stats.py --domain gsl
```

This produces the `era5.zarr` / `mur.zarr` / `bathy.npy` tensors and the
per-channel normalisation statistics consumed by `src/dataset.py`.

### 3. Train (phase 1 — encoder + baseline decoder + diffusion, jointly)

```bash
cd src
python train.py   --stage 4   --run_tag <tag>
python trainv2.py --stage 4v2 --run_tag <tag>
python trainv2.py --stage 5a  --run_tag <tag>
```

### 4. Fine-tune the diffusion head (phase 2, frozen encoder/decoder)

```bash
python finetune_diffusion.py --stage 4 \
    --ckpt ../outputs/checkpoints/stage4_T_28_<tag>_best.pt \
    --run_tag <finetune_tag> --spec_weight 5 --epochs 40

python finetune_sweep_v2.py --stage 4v2 \
    --ckpt ../outputs/checkpoints/stage4v2_T_28_<tag>_best.pt \
    --run_tag <finetune_tag> --spec_weight 5.0 --lr 1e-5 --epochs 40
```

### 5. Merge phase 1 + phase 2 checkpoints

```bash
python finetune_diffusion.py --merge --stage 4 \
    --ckpt checkpoints/stage4_T_28_<tag>_best.pt \
    --phase2_ckpt checkpoints/stage4_phase2_<finetune_tag>_best.pt

python finetune_sweep_v2.py --merge --stage 4v2 \
    --ckpt checkpoints/stage4v2_T_28_<tag>_best.pt \
    --phase2_ckpt checkpoints/stage4v2_phase2_<finetune_tag>_best.pt
```

### 6. Evaluate

```bash
python evaluate_v2.py --stage 4v2 \
    --ckpt ../outputs/checkpoints/stage4v2_<tag>_merged.pt \
    --psd_curves --save_examples
```

Reports RMSE against MUR SST, a persistence baseline, an oracle
(previous-day MUR) baseline, and spectral (PSD) skill.

### Hyperparameter sweep

`scripts/sweep/` contains a full SLURM-array sweep across stages, learning
rates, seeds, and spectral-loss weights. Configure
`scripts/sweep/generate_experiments.py` and launch with:

```bash
bash scripts/sweep/launch_sweep.sh
```

This chains three SLURM arrays (pretrain → finetune → merge+eval); see
`scripts/sweep/*.sh` for the individual stages.

## SLURM scripts

The root-level `*.sh` files are example SLURM job scripts for an
account/partition using an H100 GPU allocation — adjust `--account`,
`--gpus-per-node`, and module loads for your own cluster.
